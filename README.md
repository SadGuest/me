# Telegram-бот для мастера маникюра (aiogram + SQLite)

## Возможности
- Запись клиента на свободный слот (на 1 месяц вперед).
- Inline-календарь и inline-кнопки.
- FSM для сценариев записи и админ-функций.
- Один пользователь может иметь только одну активную запись.
- Отмена записи клиентом и админом, слот снова становится доступным.
- Проверка подписки на канал перед записью.
- Кнопки **Прайсы** и **Портфолио**.
- Уведомление админа и публикация в канал при новой записи.
- Автонапоминание за 24 часа через APScheduler.
- Восстановление задач напоминаний после перезапуска бота.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Настройка `.env`
- `BOT_TOKEN` — токен бота.
- `ADMIN_ID` — Telegram ID администратора.
- `CHANNEL_ID` — ID канала для проверки подписки и публикаций.
- `CHANNEL_LINK` — публичная ссылка на канал.

## Запуск
```bash
python bot.py
```

## Как работает напоминание
- При создании записи планируется задача за 24 часа до визита.
- Если запись менее чем через 24 часа — напоминание не ставится.
- При отмене записи задача удаляется.
- После перезапуска бота напоминания восстанавливаются из БД.
