# Telegram-бот PrCod (без Web App)

Бот работает полностью внутри Telegram через кнопки.

## Что делает
- `/start` отправляет изображение, описание PrCod и главное меню.
- Главное меню:
  - **Услуги** → 4 подпункта:
    - Разработка сайта
    - Продвижение сайта
    - Разработка приложения
    - Продвижение приложения
  - **Комбо наборы**
  - **О нас**
  - **Наши работы** (ссылка на `https://prcod.ru/our-work/`)
- На всех внутренних экранах есть кнопки **Назад**.
- В каждом разделе услуг/комбо есть кнопки **Заказать**.
- После нажатия **Заказать** бот собирает форму (имя, способ связи, контакт, комментарий)
  и отправляет заявку владельцу `@threelives`.
